# CS Quest

A study game for the TVET CDACC Level 6 Computer Science units. Each unit is a
world, each topic is a level, and every correct answer earns XP.

## How it fits together

```
Android app (Expo)  --->  API (Neon Function)  --->  Postgres database (Neon)
     app/                     api/                      database/
```

- **app/** is the game itself: React Native screens built with Expo.
- **api/** is a small server. The app only talks to this API, so the database
  password is never inside the APK. Answers are checked here, not on the phone.
- **database/schema.sql** recreates the tables. The questions live in the database.

## Screens

| Screen     | What it does                                                    |
| ---------- | --------------------------------------------------------------- |
| Onboarding | Splash and a short intro (first launch only)                    |
| Auth       | Sign up, log in, or save progress for players from before v1.2  |
| Goal       | Pick the first world after signing up                           |
| Home       | XP, streak, rank and the list of worlds                         |
| World      | Level map; levels unlock in order                               |
| Notes      | Study notes for the level, then start the quiz                  |
| Quiz       | Answer questions, get instant feedback (with sound)             |
| Result     | Stars, score, rank-ups and the level's discussion               |
| Community  | Leaderboard and the latest discussions                          |
| Profile    | Rank progress, rank ladder, sound on/off, log out               |

## Rules of the game

- Three question types: multiple choice, fill in the blank, and find the bug.
- 10 XP for a first correct answer, 2 XP for repeating one you already got right.
- Stars per level: 50% = 1 star, 70% = 2 stars, 90% = 3 stars.
- One star unlocks the next level.
- Playing on consecutive days builds a streak (days are counted in Nairobi time).
- Ranks come from levels cleared: Rookie 0, Apprentice 3, Coder 8, Debugger 15,
  Developer 25, Engineer 38, Architect 52, Grandmaster 68.
- Comments on a level are only visible to players who have played it (no spoilers).
  Three reports from different players hide a comment.
- Multiple-choice options are shuffled every time, so the right answer moves around.

## Content

7 worlds, 75 levels and 465 questions (OS, Computer Architecture, Web Dev, SQL,
Data Structures, Networking, Maths up to calculus), with notes for every level. They live in the database, so more can be added without a new APK.

## Run it on your computer

```
cd cs-quest/app
npm install
npx expo start
```

Then scan the QR code with the Expo Go app on your phone.

## Build the APK

```
cd cs-quest/app
eas build --platform android --profile preview
```

## In-app updates (no new APK needed)

The app uses EAS Update. Changes to screens, text and sounds can be shipped without a new APK:
run the **Publish app update** workflow (`app/.eas/workflows/publish-update.yml`) in the Expo
dashboard, or `eas update --channel preview` on a computer. Phones download it on the next
launch and show a "Restart" banner.

A new APK *is* needed for native changes (new native libraries, permissions, the icon or app
name). Bump `"version"` in `app.json` when you do, so old phones don't get incompatible updates.

Sound effects are generated by `tools-make-sounds.cjs`.
